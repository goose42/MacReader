# Ebook fixtures

All three are *Alice's Adventures in Wonderland* by Lewis Carroll, Project Gutenberg ebook #11 (public domain in the
United States), downloaded from gutenberg.org in each of its formats:

- `alice.epub`: the EPUB 3 with images (`/ebooks/11.epub3.images`)
- `alice-mobi6.mobi`: the Kindle MOBI 6 file (`/ebooks/11.kindle.images`)
- `alice-kf8.azw3`: the Kindle KF8 file (`/ebooks/11.kf8.images`)

They are used unmodified, and keep their Project Gutenberg licence text.
